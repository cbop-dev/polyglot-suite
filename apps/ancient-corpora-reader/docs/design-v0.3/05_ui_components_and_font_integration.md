## 1. Objective & Scope

This specification details the refactoring of the presentation tier in both `apps/ancient-corpora-reader` and the shared component library `@polyglot/ui`.

With the deletion of legacy standalone reader apps (`philo-reader`, `josephus-reader`, `af-reader`), **`ParallelColumnView.svelte` is refactored directly to accept generic text versions and dynamic language visibility sets**, permanently eliminating hardcoded language columns and edition strings.

### 2.2 Dynamic Column Layout & Responsive Grid
Instead of static conditionals checking `hasGreek`, `hasLatin`, and `hasEng`, `ParallelColumnView` computes active columns dynamically:

```ts
// Filter active versions based on visibleLanguages
let activeVersions = $derived.by(() => {
    if (!visibleLanguages || visibleLanguages.size === 0) return textVersions;
    return textVersions.filter(
        (v) => visibleLanguages.has(v.language) || visibleLanguages.has(v.versionId)
    );
});

// Dynamic responsive grid classes based on active column count
let gridColsClass = $derived.by(() => {
    if (viewMode === 'stacked' || activeVersions.length <= 1) return 'grid-cols-1';
    const count = activeVersions.length;
    if (gridBreakpoint === 'md') {
        if (count >= 3) return 'grid-cols-1 md:grid-cols-3';
        if (count === 2) return 'grid-cols-1 md:grid-cols-2';
    } else {
        if (count >= 3) return 'grid-cols-1 lg:grid-cols-3';
        if (count === 2) return 'grid-cols-1 lg:grid-cols-2';
    }
    return 'grid-cols-1';
});
```

### 2.3 Dynamic Section Row Synchronization
Rows are dynamically unified across any number of parallel text versions:
```svelte
{#each sectionKeys as secKey (secKey)}
    {@const unitsByVer = getUnitsForSection(secKey)}
    
    <div id={rowId ? rowId(secKey) : `section-${secKey}`}
         class="section-row {viewMode === 'stacked' ? 'flex flex-col gap-4' : `grid ${gridColsClass} gap-6`} py-5">
        
        {#each activeVersions as ver (ver.versionId)}
            {@const unit = unitsByVer[ver.versionId]}
            <div class="column-version {ver.fontClass}" dir={ver.direction}>
                <!-- Section Badge in primary leading column -->
                {#if ver === activeVersions[0]}
                    {#if sectionBadge}
                        {@render sectionBadge({ secKey, units: unitsByVer })}
                    {:else}
                        <span class="section-badge font-bold text-xs mr-2">§ {secKey}</span>
                    {/if}
                {/if}

                <!-- Token Word Rendering with Dynamic Font & RTL Handling -->
                {#if unit?.tokens && unit.tokens.length > 0}
                    {#each unit.tokens as tok}
                        <!-- Render Token with highlightStore & onWordClick -->
                    {/each}
                {:else if unit?.text_content}
                    <span>{unit.text_content}</span>
                {:else}
                    <span class="text-sm italic text-ink-soft">—</span>
                {/if}
            </div>
        {/each}
    </div>
{/each}
```

## 3. Refactoring `CorpusColumnView.svelte`

`CorpusColumnView.svelte` becomes a concise container bridging `readerState` and `ParallelColumnView`:

```svelte
<script lang="ts">
    import { ParallelColumnView } from '@polyglot/ui';
    import { readerState } from '../stores/readerState.svelte.js';
    import { highlightStore } from '../stores/highlightStore.svelte.js';
    import type { TextVersion } from '../stores/types.js';

    interface Props {
        textVersions: TextVersion[];
    }

    let { textVersions = [] }: Props = $props();
    let cfg = $derived(readerState.currentCorpusConfig);
</script>

<ParallelColumnView
    {textVersions}
    visibleLanguages={readerState.visibleLanguages}
    viewMode={readerState.viewMode}
    {highlightStore}
    onWordClick={(tok, citation, ver) => readerState.openToken(tok, citation)}
    onBiblicalCitationClick={(code, ch, v, disp, name) => 
        readerState.openScriptureCitation(code, ch, v, disp, name)}
>
    {#snippet sectionBadge({ secKey, units })}
        {@const milestone = cfg.milestoneScheme}
        {@const primaryUnit = Object.values(units)[0]}
        
        <div class="inline-flex items-center gap-1.5 mr-2 mb-1 select-none">
            <button type="button" class="text-xs font-mono font-bold text-blue-600 hover:underline">
                {secKey}
            </button>
            {#if milestone && primaryUnit?.milestone_ref}
                <span class="rounded px-1 py-0.2 text-[10px] font-mono {milestone.badgeColorClass}">
                    {milestone.badgePrefix} {primaryUnit.milestone_ref}
                </span>
            {/if}
        </div>
    {/snippet}
</ParallelColumnView>
```

## 4. Typography & Dynamic Font Integration

### 4.1 Integration with `@polyglot/ancient-languages`
Instead of duplicating font classes in `app.css`, ACR utilizes `@polyglot/ancient-languages/fonts.ts`:
* [`getLanguageFontClass(language)`](file:///home/cbrannan/.gemini/antigravity/worktrees/polyglot-suite/audit_acr_refactoring/packages/ancient-languages/src/fonts.ts#L41-L58): Returns standard CSS utility classes (e.g. `'font-greek greek'`, `'font-latin latin'`, `'font-hebrew hebrew'`, `'font-syriac syriac'`).
* [`isRtlLanguage(language)`](file:///home/cbrannan/.gemini/antigravity/worktrees/polyglot-suite/audit_acr_refactoring/packages/ancient-languages/src/fonts.ts#L63-L69): Dynamically assigns text direction (`'rtl'` vs `'ltr'`).

### 4.2 Cleaned `src/app.css`
Delete hardcoded `.greek-font` and `.latin-font` rules from `app.css`. Rely on the font family variables exported by `@polyglot/ancient-languages` and the design token system in `@polyglot/theme`.
