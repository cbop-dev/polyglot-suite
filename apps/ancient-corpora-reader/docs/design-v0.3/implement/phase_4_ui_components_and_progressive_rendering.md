      textVersions: TextVersion[];
      visibleLanguages?: Set<string>;

* **Implement Dynamic Columns**:
  - Filter active versions: `activeVersions = textVersions.filter(v => visibleLanguages.has(v.language) || visibleLanguages.has(v.versionId))`.
  - Compute responsive grid: `gridColsClass` adapts automatically to 1, 2, 3, or $N$ columns.
* **Implement Progressive Batch Rendering Engine**:
  - State: `renderedCount = $state(25)`.
  - Slice: `renderedKeys = $derived(sectionKeys.slice(0, renderedCount))`.
  - Loop: incremental scheduling via `requestIdleCallback` (150ms timeout) appending 25 sections per tick.
  - Target section jump handler: `Math.max(25, targetIndex + 15)` to guarantee immediate visibility on direct jumps.
  - Sentinel: append `<div class="render-sentinel">` observed by `IntersectionObserver` to trigger emergency batch advance on rapid scrolling.
* **Apply Dynamic Typography**:
  - Wrap columns with `class={ver.fontClass}` and `dir={ver.direction}`.
