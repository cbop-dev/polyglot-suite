## 2. Step-by-Step Implementation Tasks

### Task 2.1: Enforce Canonical DDL in `pipeline/db_builder.py`
Update `build_optimized_corpus_db()` to create the unified relational tables:
1. `corpus_versions`: populated with the text versions present in the database (e.g. `lake_grc`, `lake_eng`, `af_lat`).
2. `corpus_works`: populated with standardized work codes (`1CLE`, `OPIF`, `WAR`), titles, and division structures.
3. `text_units`: standardized coordinates `(work_code, book, chapter, section)` and unified `milestone_ref`.
4. `text_unit_tokens`: clean token storage keyed on `work_unit_id` (or inline on `text_units` per Option A).
5. `concordance_refs`: zero-join covering table with precomputed 60-character KWIC snippets.
6. `lemma_forms`: unified precomputed inflections table.
7. `lexicon_entries`: standardized dictionary table.

### Task 2.2: Implement Universal `lemma_forms` Precomputation
Eliminate the Tier 2.6 gap by ensuring all three corpora precompute inflected forms at build time:
* **Josephus**:
  - Read from source `attested_forms` (`lemma`, `form`, `pos`, `parse_code`, `description`).
  - Aggregate into canonical JSON: `[{"word":"...", "pos":"...", "parse":"...", "count":n}]`.
  - Insert into `lemma_forms(corpus_id, lemma_key, normalized_lemma, forms_json)`.
* **Philo**:
  - Read from source `lemma_forms`, normalize JSON structure, and write to canonical `lemma_forms`.
* **Apostolic Fathers**:
  - In `db_builder.py`, iterate over all tokens in `text_unit_tokens`.
  - Group word tokens by lemma (`tok.l` -> `tok.w`, `tok.m`, `tok.p`) and compute frequency counts.
  - Insert aggregated forms into `lemma_forms`.
  - *Result*: Zero runtime table scans or joins needed for AF attested forms.
